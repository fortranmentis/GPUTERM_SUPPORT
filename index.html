GpuTerm Support

GpuTerm is an SSH terminal, SFTP file browser and live GPU, thermal and LLM monitor for iPhone and iPad. It requires iOS 26 or later and an SSH server you can sign in to.

Email vin9604@gmail.com. Include your device model, iOS version, GpuTerm version (shown under Sessions › About) and the server's operating system. Please don't send passwords or private keys.

Common questions

The app can't reach a server on my network

Allow local network access under iOS Settings › Privacy & Security › Local Network › GpuTerm, then try again.

GpuTerm says the host key changed

The server presented a different key from the one you trusted. This is expected after reinstalling the server's operating system or SSH service. Otherwise, it could mean someone is intercepting the connection. Check the new fingerprint with the server's administrator before replacing the key.

The Monitor shows no GPU data

GPU readings come from the vendor's command-line tools on the server, such as nvidia-smi. Make sure the tool is installed and works for your SSH user.

What does iCloud sync include?

Profiles, snippets and trusted host keys. Passwords that don't require Face ID sync through iCloud Keychain. Private keys stay on each device. See the Privacy Policy for details.

How do I move my servers to a new device without iCloud?

Use Sessions › Security › Export sync file, then Import sync file on the new device. Re-enter passwords and import private keys on the new device.

Where can I find open-source licenses?

In the app, under Sessions › About › Licenses.
